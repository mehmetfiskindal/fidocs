# Getting Started

Install and run Fidocs in minutes.

## Installation

```bash
npm install fidocs
```

## Your first doc

Create `docs/index.md` with frontmatter:

```markdown
---
title: Hello
---
# Hello world
```

## Build

| Command | Description |
| --- | --- |
| `fidocs build` | Emit static HTML |
| `fidocs dev` | Live reload server |

> Zero dependencies. Really.
